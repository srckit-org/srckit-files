# srckit-files

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Upload files to inspect metadata and compute cryptographic hashes.

## Features

- **Upload** — Choose a file to see name, size, type, last modified, and text preview
- **Hash** — Compute SHA-1, SHA-256, SHA-384, or SHA-512 hashes of any file using Web Crypto API

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
